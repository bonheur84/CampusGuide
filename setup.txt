🎓 GUIDE DE CONFIGURATION CAMPUSGUIDE

1. STRUCTURE DU PROJET
---------------------
- /backend : Serveur Node.js + Express
- /frontend : Application React + Vite

2. CONFIGURATION DE LA BASE DE DONNÉES (MySQL)
--------------------------------------------
- Assurez-vous que MySQL est installé et démarré.
- Ouvrez votre terminal MySQL (ou MySQL Workbench / phpMyAdmin).
- Exécutez le script SQL situé dans : backend/src/database/schema.sql
- Cela créera la base "campusguide" et les tables nécessaires.

3. CONFIGURATION DU SERVEUR
--------------------------
- Ouvrez le fichier : backend/.env
- Modifiez DB_PASSWORD avec VOTRE mot de passe MySQL (laissez vide si pas de mot de passe).
- Modifiez DB_USER si votre utilisateur n'est pas "root".

4. LANCEMENT DU PROJET
---------------------
- À la racine du projet, ouvrez un terminal et tapez :
  npm install
- Puis lancez tout avec une seule commande :
  npm start

- Le Backend sera sur : http://localhost:3001
- Le Frontend sera sur : http://localhost:5173
